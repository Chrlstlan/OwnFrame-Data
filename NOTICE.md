# Notice — Data Sources and Attribution

This repository contains game data for Digital Extremes' game Warframe,
restructured for OwnFrame's use. Nothing in this repository is official
Warframe content.

## Sources

| Data | Source |
|---|---|
| Item names, descriptions, stats, recipes, mod data | Digital Extremes official Public Export (`content.warframe.com/PublicExport`) |
| Item images | Digital Extremes official Public Export image CDN (`content.warframe.com/PublicExport`) |
| Drop tables (missions, enemies, relics) | Digital Extremes official drop data |
| Tradable item slugs | [warframe.market](https://warframe.market) public item data |
| Per-locale name overlays | Digital Extremes localized Public Exports, plus community corrections |
