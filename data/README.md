## Local wiki / web catalog

Copy a rebuilt English catalog to `data/All.en.json` for OwnFrame-Web wiki
dev (`npm run dev`). The file is gitignored (~16MB); CI should publish it
as a release asset later.

```bash
# from the OwnFrame umbrella, after the App has a fresh All.json
cp OwnFrame-App/src/public/All.json OwnFrame-Data/data/All.en.json
```
